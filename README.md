# ConsoleSelenium41

Projeto de automação de testes desenvolvido em C# utilizando Selenium WebDriver e MSTest.

## Tecnologias utilizadas

- C#
- .NET 10
- Selenium WebDriver
- Selenium Support
- MSTest
- Git e GitHub

## Exercícios desenvolvidos

### Exercício 1 — Cadastro completo
- Preenchimento de campos de texto.
- Preenchimento de senha.
- Validação de campo somente leitura.
- Envio do formulário.
- Verificação da mensagem de sucesso.

### Exercício 2 — Dropdown e Datalist
- Seleção de opção em dropdown.
- Validação do valor selecionado.
- Preenchimento de datalist.
- Verificação do envio do formulário.

### Exercício 3 — Checkboxes, Radios e Color Picker
- Seleção de checkboxes.
- Seleção de radio button.
- Alteração de Color Picker.
- Validação dos elementos.
- Verificação do envio do formulário.

## Como executar

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Acesse a pasta:

```bash
cd ConsoleSelenium41
```

Execute os testes:

```bash
dotnet test
```
